# App Settings Audit Docs

## Implementation Audit
- `APP_SETTINGS_IMPLEMENTATION_AUDIT_REPORT.md` — status vs checklist, flows, verification, and gaps.

## Test Cases
- `APP_VERSION_UPDATE_TEST_CASES.md` — step-by-step manual test cases for app version & update feature (phiên bản & cập nhật: AppVersions, changelog, bắt buộc nâng cấp; compatibility backend/schema), covering current missing implementation (no AppVersion screen/service, no forced-upgrade check, no schema compatibility check) and required fixes. Includes test cases for app version display, changelog display, forced upgrade check, optional upgrade notification, automatic version check on app launch, backend/schema compatibility check, remote version retrieval, app store integration, and manual version check.

- `UI_CUSTOMIZATION_TEST_CASES.md` — step-by-step manual test cases for UI customization feature (tùy chỉnh giao diện: đổi màu chủ đạo, theme sáng/tối; lưu theo workspace/thiết bị), covering current partial implementation (theme files exist, WorkspaceSettingsPage lets set theme per workspace, but primary color change not supported per workspace; per-workspace persistence is partial; app-wide theme toggle page exists) and required fixes. Includes test cases for app-wide theme mode switching (light/dark/system), app-wide primary color change, per-workspace theme mode, per-workspace primary color, workspace switching with theme/color persistence, device-level theme persistence, primary color palette safety, and theme/color reset to defaults.

- `SYSTEM_SETTINGS_TEST_CASES.md` — step-by-step manual test cases for system settings feature (hệ thống: ngôn ngữ, định dạng ngày/giờ, timezone mặc định; quyền truy cập dữ liệu nền notifications/sync), covering current partial implementation (workspace settings capture language/timezone/date/time format, but no global app settings page exists; no background data permission handling) and required fixes. Includes test cases for app-wide language/timezone/date/time format settings, workspace language/timezone/date/time override, background data permission checking and requesting, notification permission management, background sync permission checking, and system settings persistence.

- `OFFLINE_CACHE_POLICY_TEST_CASES.md` — step-by-step manual test cases for offline cache policy feature (chính sách lưu trữ offline: cache size, auto-clear), covering current missing implementation (not implemented) and required fixes. Includes test cases for cache size display and calculation, cache auto-clear policy configuration, automatic cache cleanup, manual cache clear (all cache and by category), cache size limit setting, cache cleanup scheduling, cache policy persistence, and cache size warning.

- `MAINTENANCE_UPGRADE_BANNER_TEST_CASES.md` — step-by-step manual test cases for maintenance/upgrade banner feature (banner thông báo bảo trì/nâng cấp), covering current missing implementation (not implemented) and required fixes. Includes test cases for maintenance banner display, upgrade banner display, banner dismissal, banner configuration from remote config, banner priority handling, banner persistence, banner styling, banner actions, banner scheduling, and banner refresh from remote config.

## Task Lists
- `APP_VERSION_UPDATE_TASKS.md` — detailed task list and expected results for completing the app version & update feature, including adding package info dependency and creating app version service, creating remote version check service, creating forced upgrade dialog and gate, creating optional upgrade notification, creating changelog display service and UI, creating backend/schema compatibility check service, and creating app version settings page. Focuses on ensuring app version is displayed, changelog is shown, forced upgrade blocks app usage, optional upgrade notifies users, and backend/schema compatibility is checked.

- `UI_CUSTOMIZATION_TASKS.md` — detailed task list and expected results for completing the UI customization feature, including enhancing WorkspaceSettings entity to support primary color, creating workspace theme service, adding primary color picker to WorkspaceSettingsPage, improving per-workspace theme integration, adding reset to defaults functionality, and improving palette safety for primary color. Focuses on ensuring primary color can be set per workspace, theme mode can be set per workspace, workspace theme/color is applied when switching workspaces, per-workspace settings persist correctly, and palette safety is maintained.

- `SYSTEM_SETTINGS_TASKS.md` — detailed task list and expected results for completing the system settings feature, including creating app-wide system settings service, creating system settings controller, adding system settings section to AppSettingsPage, creating background data permission service, adding background data permission section to AppSettingsPage, and integrating workspace override with app-wide settings. Focuses on ensuring app-wide system settings can be set, system settings persist correctly, background data permission can be checked, notification permission can be requested, workspace overrides work correctly, and app-wide defaults are used when no workspace override.

- `OFFLINE_CACHE_POLICY_TASKS.md` — detailed task list and expected results for completing the offline cache policy feature, including creating cache size calculation service, creating cache policy service, creating cache cleanup service, creating cache settings controller, adding cache settings section to AppSettingsPage, and creating cache auto-clear scheduler. Focuses on ensuring cache size is calculated accurately, cache size is displayed with breakdown, cache policy can be configured, cache can be cleared manually (all or by category), cache is auto-cleared according to policy, cache size limit is enforced, scheduled cleanup works correctly, and policy settings persist after app restart.

- `MAINTENANCE_UPGRADE_BANNER_TASKS.md` — detailed task list and expected results for completing the maintenance/upgrade banner feature, including creating banner service for remote config integration, creating banner controller, creating banner widget, integrating banner into app scaffold, adding banner refresh on app launch, and adding banner scheduling support. Focuses on ensuring maintenance banner is displayed when maintenance mode is active, upgrade banner is displayed when upgrade is available, banner configuration is retrieved from remote config, banner can be dismissed, banner dismissal persists, banner priority is handled correctly, banner scheduling works correctly, and banner refresh works correctly.
