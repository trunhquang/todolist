# Reports & Analytics Audit Docs

## Implementation Audit
- `REPORTS_IMPLEMENTATION_AUDIT_REPORT.md` — status vs checklist, flows, verification, and gaps.

## Test Cases
- `REPORT_OVERVIEW_AGGREGATION_TEST_CASES.md` — step-by-step manual test cases for report overview aggregation feature (total tasks by status/priority/type workspace-wide), covering current partial implementation (entities/controllers for reports exist but aggregation logic over tasks by status/priority/type not found; no task-enum enforcement; metrics field is generic) and required fixes.
- `REPORT_CHARTS_TEST_CASES.md` — step-by-step manual test cases for report charts feature (bar/pie charts for tasks per status/priority), covering current partial implementation (dashboard has metrics placeholders but dedicated chart implementation for reports not evident; no charts tied to reports feature) and required fixes.
- `REPORT_FILTERING_TEST_CASES.md` — step-by-step manual test cases for report filtering feature (filtering by workspace/project/team/group/assignee and date range), covering current partial implementation (`ReportEntity` carries `workspaceId` and `completedTaskIds`; no filtering/query layer shown for project/team/assignee or date range; no UI for scoped filtering) and required fixes.
- `PROJECT_ANALYTICS_TEST_CASES.md` — step-by-step manual test cases for project analytics feature (project status, completion rate, burnup/burndown, overdue/near-due task list), covering current partial implementation (`project_progress_card.dart` exists; no dedicated project analytics in reports module; overdue/near-due listing not implemented) and required fixes.
- `REPORT_EXPORT_IMPORT_TEST_CASES.md` — step-by-step manual test cases for report export/import feature (Excel/PDF export, import, saved filter configurations), covering current missing implementation (no export/import or saved-filter implementation found) and required fixes.
- `REPORT_ACCESS_CONTROL_TEST_CASES.md` — step-by-step manual test cases for report access control feature (role-based access control for reports), covering current missing implementation (no access control specific to reports; relies on generic roles only) and required fixes.
