# Notifications Audit Docs

## Implementation Audit
- `NOTIFICATIONS_IMPLEMENTATION_AUDIT_REPORT.md` — status vs checklist, flows, verification, and gaps.

## Test Cases
- `NOTIFICATION_ARCHITECTURE_TEST_CASES.md` — step-by-step manual test cases for notification architecture feature (each device has its own BE service, sync Firebase token + deviceId; use FCM push when adding/deleting/editing/assigning tasks, changing roles), covering current missing implementation (only `NotificationEntity` exists; no device/FCM registration, no service layer, no push triggers) and required fixes.
- `NOTIFICATION_MAIN_FLOW_TEST_CASES.md` — step-by-step manual test cases for notification main flow feature (save token/deviceId on login/refresh; push when task/project/workspace membership changes; retry/fallback; revoke token on logout), covering current missing implementation (`AuthController` saves ID token to StorageService (not FCM), no deviceId, no refresh/retry/revoke flows) and required fixes.
- `NOTIFICATION_SUBSCRIPTION_MANAGEMENT_TEST_CASES.md` — step-by-step manual test cases for notification subscription management feature (enable/disable notification groups: task updates, mentions, workspace changes; DND/quiet hours), covering current missing implementation (not implemented; no user prefs or UI for categories/DND) and required fixes.
- `NOTIFICATION_OBSERVATION_AUDIT_TEST_CASES.md` — step-by-step manual test cases for notification observation & audit feature (log notification sending: success/fail, retry count; statistics: success rate, fail rate, invalid tokens), covering current missing implementation (not implemented; no logging/metrics) and required fixes.
- `NOTIFICATION_CENTER_TEST_CASES.md` — step-by-step manual test cases for notification center feature (in-app notification center, read/unread state; real-time vs digest mode; quota/throttle warnings), covering current missing implementation (not implemented; no in-app inbox, no digest logic, no quota handling) and required fixes.

## Task Lists
- `NOTIFICATION_ARCHITECTURE_TASKS.md` — detailed task list and expected results for completing the notification architecture feature, including creating device registration entity, creating device registration service, adding device registration methods to FirebaseDatabaseService, integrating device registration with login flow, creating push notification service, adding push triggers for task operations, adding push triggers for role changes, adding retry/fallback mechanism, adding invalid token cleanup, and unit tests.
- `NOTIFICATION_MAIN_FLOW_TASKS.md` — detailed task list and expected results for completing the notification main flow feature, including saving FCM token and deviceId on login, handling FCM token refresh, adding push triggers for task/project/workspace operations, implementing retry/fallback mechanism, implementing token revocation on logout, adding error handling, and unit tests.
- `NOTIFICATION_SUBSCRIPTION_MANAGEMENT_TASKS.md` — detailed task list and expected results for completing the notification subscription management feature, including creating NotificationPreferences entity, creating NotificationPreferencesService, adding notification preferences methods to FirebaseDatabaseService, updating NotificationSettingsPage with required categories (task updates, mentions, workspace changes), adding DND mode, adding quiet hours configuration, adding preference checking to push notification service, adding workspace scoping for preferences, and unit tests.
- `NOTIFICATION_OBSERVATION_AUDIT_TASKS.md` — detailed task list and expected results for completing the notification observation & audit feature, including creating NotificationLog entity, creating NotificationStatistics entity, creating NotificationLoggingService, adding notification log methods to FirebaseDatabaseService, integrating logging with push notification service, creating NotificationStatisticsService, adding notification statistics methods to FirebaseDatabaseService, creating notification statistics dashboard page, adding invalid token tracking, adding log export functionality, and unit tests.
- `NOTIFICATION_CENTER_TASKS.md` — detailed task list and expected results for completing the notification center feature, including creating NotificationCenterController, creating NotificationCenterPage, creating TDNotificationItem widget, adding unread count badge to app bar, adding notification methods to FirebaseDatabaseService, creating NotificationDigestService, creating QuotaThrottleMonitoringService, integrating digest mode with notification preferences, adding notification center route, and unit tests.
