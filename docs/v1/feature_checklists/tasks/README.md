- `TASK_CLASSIFICATION_COLOR_TEST_CASES.md` — step-by-step manual test cases for task classification (Daily/Project) & color by status feature, covering current partial implementation (taskType string supports daily/project but not enforced by enum, color mapping not centralized/consistent) and required fixes.
- `TASK_STATISTICS_FILTERING_TEST_CASES.md` — step-by-step manual test cases for task statistics & filtering feature (status/priority/assignee/tag/workspace/project/team), covering current partial implementation (pagination/filter basics exist but tag/team filters are missing, workspace filter guard not confirmed, sorting/filter UIs not evident) and required features.
- `TASK_PERFORMANCE_SYNC_TEST_CASES.md` — step-by-step manual test cases for task performance & sync feature (server-side pagination via FirebaseDatabaseServiceEnhanced, offline cache, conflict resolution), covering current partial implementation (uses FirebaseDatabaseService with no Enhanced version in repo, pagination tests exist but enhanced service not found, offline cache/conflict resolution not found or not fully integrated) and required features.
- `RECURRING_TASKS_TEST_CASES.md` — step-by-step manual test cases for recurring tasks feature, covering current partial implementation (TaskEntity.recurring + generate_recurring_tasks.dart use case exist; UI wiring unclear; no scheduler hook observed in controllers) and required fixes.
- `TASK_DEPENDENCIES_BLOCKERS_TEST_CASES.md` — step-by-step manual test cases for task dependencies/blockers feature, covering current missing implementation (not implemented; only parentTaskId for recurring instances, not blockers) and required features.
- `TASK_SLA_OVERDUE_NOTIFICATIONS_TEST_CASES.md` — step-by-step manual test cases for task SLA overdue notifications feature, covering current missing implementation (not implemented; no SLA timers or notifications) and required features.
- `TASK_EXPORT_IMPORT_TEST_CASES.md` — step-by-step manual test cases for task export/import subset (backup linkage) feature, covering current missing implementation (not implemented; no export/import flow) and required features.
