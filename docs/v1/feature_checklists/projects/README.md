# Projects Audit Docs

## Implementation Audit
- `PROJECTS_IMPLEMENTATION_AUDIT_REPORT.md` — status vs checklist, flows, verification, and gaps.

## Test Cases
- `PROJECT_CRUD_LIFECYCLE_TEST_CASES.md` — step-by-step manual test cases for project CRUD & lifecycle feature (create/edit/archive/restore/delete with permissions), covering current partial implementation (create/edit/delete exist but archive/restore missing and permissions not enforced in UI) and missing features.
- `PROJECT_STATUS_ENUM_TEST_CASES.md` — step-by-step manual test cases for project status enum feature, covering current partial implementation (ProjectStatus enum exists but Project entity uses String status instead of enum, and enum is not enforced through controllers/UI) and required fixes.
- `PROJECT_TASKS_TEST_CASES.md` — step-by-step manual test cases for tasks within project feature (add/remove/edit; assign team/group/member; filters by status/priority/assignee/tag; status breakdown), covering current partial implementation (tasks link via projectId but team/group assignment, tags, and status breakdown are missing) and missing features.
- `PROJECT_SCOPE_PERMISSIONS_TEST_CASES.md` — step-by-step manual test cases for project scope & permissions feature (workspace + role/team; project membership assign/revoke/roles), covering current partial implementation (workspace scoping exists but project member roles/permissions and UI to assign/revoke are missing) and missing features.
- `PROJECT_TRACKING_REPORTING_TEST_CASES.md` — step-by-step manual test cases for project tracking & reporting feature (project dashboard, task charts, burndown/burnup, overdue/near-due list, change log for status/members/deadline/budget), covering current partial implementation (project_progress_card.dart provides progress display but burndown/burnup, change log, and overdue/near-due lists are missing) and missing features.
- `PROJECT_MILESTONES_PHASES_TEST_CASES.md` — step-by-step manual test cases for milestones/phases linked to tasks feature, covering current missing implementation (no milestone entity/UI exists, tasks cannot be linked to milestones/phases) and required features.
- `PROJECT_TEMPLATES_TEST_CASES.md` — step-by-step manual test cases for project templates (predefined task sets) feature, covering current missing implementation (no project template entity/UI exists, projects cannot be created from templates with predefined tasks) and required features.

## Task Lists
- `PROJECT_CRUD_LIFECYCLE_TASKS.md` — detailed task list and expected results for completing the project CRUD & lifecycle feature, including archive/restore fields in Project entity, archive/restore use cases, repository and Firebase methods, controller methods with permission checks, UI for archive/restore, permission checks in UI, confirmation dialogs, and archived projects view.
- `PROJECT_STATUS_ENUM_TASKS.md` — detailed task list and expected results for completing the project status enum feature, including updating Project entity to use ProjectStatus enum instead of String, updating controllers/repositories/UI to use enum, adding color mapping, creating status dropdown widget, updating filters, and adding validation.
- `PROJECT_TASKS_TASKS.md` — detailed task list and expected results for completing the tasks within project feature, including adding tags and team/group assignment fields to TaskEntity, creating project tasks view UI, adding/removing tasks from project, assigning tasks to teams/groups, creating filters UI, adding tag/team filters to FirebaseDatabaseService, creating status breakdown widget, and unit tests.
- `PROJECT_SCOPE_PERMISSIONS_TASKS.md` — detailed task list and expected results for completing the project scope & permissions feature, including creating ProjectMember entity, ProjectRole enum, ProjectPermissions constants, project member repository, use cases for add/remove/update role, project access control service, project member management UI, team assignment support, and unit tests.
- `PROJECT_TRACKING_REPORTING_TASKS.md` — detailed task list and expected results for completing the project tracking & reporting feature, including creating project dashboard page, task status/priority/assignee distribution charts, burndown/burnup chart use cases and widgets, overdue/near-due tasks list widgets, project change log service and repository, change log UI, integrating change logging with project operations, completion trend chart, and export functionality.
- `PROJECT_MILESTONES_PHASES_TASKS.md` — detailed task list and expected results for completing the milestones/phases linked to tasks feature, including creating Milestone entity, adding milestoneId field to TaskEntity, creating milestone repository and use cases (create, update, delete, link, calculate progress), creating milestone management UI, adding milestone selector to task edit UI, creating milestone progress widget, milestone completion detection, milestone filtering, ordering support, bulk link operations, and unit tests.
- `PROJECT_TEMPLATES_TASKS.md` — detailed task list and expected results for completing the project templates (predefined task sets) feature, including creating ProjectTemplate entity with TemplateTask and TemplateVisibility, creating template repository and use cases (create, update, delete, get templates, create project from template, create template from project), creating template list/preview/management UI, creating project from template UI with customization, default templates, template categories, template sharing, usage statistics, and unit tests.
