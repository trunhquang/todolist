## Test Cases
- `EXCEL_EXPORT_TEST_CASES.md` — step-by-step manual test cases for Excel export feature (export Excel list of tasks/projects, hidden if not enabled), covering current missing implementation (not implemented; no export pipeline or toggle) and required fixes.
- `SCHEDULED_BACKUP_TEST_CASES.md` — step-by-step manual test cases for scheduled backup feature (backup định kỳ lên OneDrive/Firebase Storage cho Account Holder/Admin), covering current missing implementation (not implemented; no backup scheduler/service or role guard) and required fixes.
- `BACKUP_SCOPE_TEST_CASES.md` — step-by-step manual test cases for backup scope feature (phạm vi backup: tasks, projects, workspace settings, thành viên tùy chọn), covering current missing implementation (not implemented; no data selection or packaging logic) and required fixes. Includes test cases for tasks, projects, workspace settings, members (optional), complete backup, partial backup, empty workspace, large workspace, data exclusion, and file format validation.
- `BACKUP_DATA_EXCLUSION_TEST_CASES.md` — step-by-step manual test cases for backup data exclusion feature (token/deviceId không backup; chỉ backup metadata cần thiết), covering current missing implementation (not implemented; no backup logic to enforce exclusions) and required fixes. Includes test cases for token exclusion, deviceId exclusion, password exclusion, API keys exclusion, complete sensitive data exclusion, metadata inclusion, nested data exclusion, case-insensitive exclusion, partial match exclusion, and exclusion validation.
- `BACKUP_RESTORE_TEST_CASES.md` — step-by-step manual test cases for backup restore feature (khôi phục workspace/project từ bản backup với kiểm tra quyền), covering current missing implementation (not implemented; no restore flows, no audit trail) and required fixes. Includes test cases for restore permission checks (Account Holder, Admin, Member), complete workspace restore, selective project restore, restore validation (invalid backup, workspace mismatch), conflict resolution, restore audit trail, and error handling.
- `BACKUP_RESTORE_AUDIT_TRAIL_TEST_CASES.md` — step-by-step manual test cases for restore audit trail feature (nhật ký khôi phục: ai khôi phục, từ bản nào, thời gian), covering current missing implementation (not implemented) and required fixes. Includes test cases for logging who restored (user information), logging from which backup (backup file information), logging when restored (timestamp), complete log entry verification, multiple restore operations, different users restore, failed restore logging, log entry viewing/filtering, log entry export, and log entry retention.
- `BACKUP_SECURITY_TEST_CASES.md` — step-by-step manual test cases for backup security feature (an toàn: mã hóa file backup, ký checksum; retention/auto-cleanup), covering current missing implementation (not implemented) and required fixes. Includes test cases for backup file encryption, backup file decryption, checksum calculation and signing, checksum verification during restore, backup retention policy, backup auto-cleanup, retention policy types (keep latest N, keep by date range), encryption key management, and checksum signature verification.
- `BACKUP_AUTOMATION_TEST_CASES.md` — step-by-step manual test cases for backup automation feature (thiếu: lịch backup tự động, thông báo khi thất bại; kiểm tra giới hạn dung lượng), covering current missing implementation (not implemented) and required fixes. Includes test cases for scheduled backup automation, backup schedule configuration, failure notifications, multiple failure notifications, storage quota checking, quota display and monitoring, quota exceeded prevention, notification preferences, backup schedule persistence, and quota check for scheduled backup.

## Task Lists
- `EXCEL_EXPORT_TASKS.md` — detailed task list and expected results for completing the Excel export feature, including adding Excel package to pubspec.yaml, creating feature toggle entity and service, creating ExcelExportService, adding export UI to task/project pages (hidden when toggle is disabled), adding permission checks, adding file sharing functionality, and unit tests.
- `SCHEDULED_BACKUP_TASKS.md` — detailed task list and expected results for completing the scheduled backup feature, including adding role guard to BackupService, implementing exportDataToOneDrive() method, creating FirebaseStorageBackupService, adding backup destination selection, adding backup scheduler configuration, adding backup settings UI, adding failure notification system, adding storage quota checking, adding backup progress indicator, and unit tests.
- `BACKUP_SCOPE_TASKS.md` — detailed task list and expected results for completing the backup scope feature, including implementing data selection logic for tasks, projects, workspace settings, and members (optional), implementing data packaging logic, adding backup scope selection UI, adding sensitive data exclusion validation, adding backup file format validation, updating BackupController to support scope, and adding comprehensive error handling and logging.
- `BACKUP_DATA_EXCLUSION_TASKS.md` — detailed task list and expected results for completing the backup data exclusion feature, including creating sensitive data exclusion list, implementing recursive sensitive data filter, applying exclusion to task/project/workspace/member data conversion, adding backup payload validation, and adding exclusion logging and monitoring. Focuses on ensuring tokens, deviceId, passwords, API keys, and other sensitive data are excluded from backup files.
- `BACKUP_RESTORE_TASKS.md` — detailed task list and expected results for completing the backup restore feature, including adding restore permission checks (Account Holder/Admin only), implementing backup file validation, implementing workspace restore logic (workspace settings, projects, tasks, members), implementing restore audit trail, adding restore confirmation dialog, and adding restore progress tracking. Focuses on ensuring secure restore operations with proper permission checks and complete audit logging.
- `BACKUP_RESTORE_AUDIT_TRAIL_TASKS.md` — detailed task list and expected results for completing the restore audit trail feature, including creating restore audit log entity, creating restore audit log service, integrating audit logging with restore operations, creating restore audit log repository, and creating restore audit log UI. Focuses on logging who restored (user information), from which backup (backup file information), when restored (timestamp), and what was restored (details) for complete audit trail.
- `BACKUP_SECURITY_TASKS.md` — detailed task list and expected results for completing the backup security feature, including adding encryption package and creating encryption service, integrating encryption/decryption with backup/restore services, creating checksum service and integrating with backup/restore services, creating backup retention policy service, adding scheduled auto-cleanup, and adding retention policy UI. Focuses on ensuring backup files are encrypted (AES-256), have checksum (SHA-256), retention policy is configurable, and auto-cleanup works according to policy.
- `BACKUP_AUTOMATION_TASKS.md` — detailed task list and expected results for completing the backup automation feature, including enhancing scheduled backup configuration (daily, weekly, monthly), creating backup failure notification service, creating storage quota checking service, integrating quota check with scheduled backup, adding quota display to backup settings UI, adding backup schedule UI, and adding failure notification preferences UI. Focuses on ensuring scheduled backup runs automatically, failure notifications are sent when backup fails, storage quota is checked before backup, and backup is prevented if quota is exceeded.
